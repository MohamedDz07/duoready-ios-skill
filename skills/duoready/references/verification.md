# Verification protocol

Separate three claims:

1. **Source claim** — a static pattern was found by the audit.
2. **Compile claim** — a sample type-checks or builds with a named SDK and target.
3. **Behavior claim** — a running app was observed in a named pose, runtime, or device.

Never use a source scan as evidence of runtime behavior. Never use a successful type-check as evidence that a pane lands correctly. Never use a screenshot without recording the pose and runtime.

Minimum matrix: compact window, regular window, wide window, short height, Dynamic Type, RTL, VoiceOver focus order, keyboard, background/foreground, state restoration, and any supported split-view or multiple-scene configuration.
